# Focused proof before performance

Normal native and generic-ASan builds compile the same22-config actual caller and two-hint clone. Structured Cargo artifact IDs bind all four local crates. Every actual `.d` source is resolved and checked against committed local sources or the previously pinned external trees **before** any test/filter invocation. No new dependency version or network resolution is permitted. Fresh target and output paths reject even dangling pre-existing symlinks; failed attempts remain untouched.

Each mode executes exactly three focused tests: whole bitmap/public-output equivalence of the old/new K12 chain, actual timed-tail corruption detection in all four modes, and balanced query-phase order. Tiny fixtures use seen seed42, n1024, q4096, four repetitions and calibration0: four3-row K12/clone/Range cases at budget24 and b1/3/31/4096, plus one22-row registry smoke at budget16/b3. Total68 new caller rows,29 original-binary references,58 retained complete semantic comparisons. Six malformed CLI calls must reject before CSV output. This does not repeat the earlier kernel/backend/parallel suite or collect new FPR calibration.

The candidate/original full bitmaps are compared after duplicate/partial/hotspot insertion at four byte budgets (including nonpowers-of-two and the prefetch threshold). Both singleton and dense outputs for every tail0..131 and4096, offsets0/3, no false negatives, guards, immutable input/bitmap and invalid-output-length rejection are checked. Exact source derivation proves the remaining public operations are unchanged.

The normal linked binary is inspected through raw/demangled symbol inventories and address-bounded `objdump` ranges. Every selected capture must contain real instructions covering its expected symbol; both visible pure and fused/raw specializations must exist for old and new crates. Read-only review determines whether hot helper calls remain. There is no automatic successful-inlining assumption, no new annotation search, and no formal performance in this driver.

The complete operation owns the inherited exclusive socket1 flock and stays onCPU3. These tests exercise serial public caller paths; previous real multi-core ownership proof remains linked. The driver rejects implicit compiler/loader/sanitizer/allocator overrides, records exact tools/flags/artifacts, and rechecks source, binaries and lease on completion.
