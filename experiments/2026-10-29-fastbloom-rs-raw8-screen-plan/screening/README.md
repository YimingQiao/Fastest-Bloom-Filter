# Frozen raw8 runner preparation

This additive driver executes the unchanged [proposal](../README.md) only after its source commit and an explicit launch grant. It reuses the already-proven native binary `c7aa0e69…`; it never rebuilds, changes adapters, selects configurations from accuracy, or runs the old preflight suite. The 18 exact commands produce 786 rows, including all 144 new fastbloom-rs K1–24 geometries at every query batch.

The parent holds `/tmp/fastest-bf-socket0.lock`, pins CPU2 and sets `BF_SOCKET_LEASE=socket0-cpu2`. The runner proves an actual inherited exclusive FLOCK descriptor and passes it to every child. Every measured command explicitly uses the hashed `numactl --physcpubind=2 --membind=0`. An untimed `numactl --show` child first verifies the effective CPU and memory policy. Failure aborts; there is no affinity-only fallback.

The source/binary freeze binds the committed proposal, all completed proof artifacts, actual compiler input closures, four proven executables, toolchains, external sources and the numactl executable. It rechecks these before and after the matrix. All geometry, public API, scratch, phase, four metric/trial and checksum field checks remain unchanged.
