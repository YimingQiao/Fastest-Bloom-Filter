# Versioned preflight, before compiler execution

The initial27-file proposal and its `PREPARATION.json` remain byte-identical to commit`aba1dbdaa6154540ced8fe466521625a23f69af8`. `validate.py` is preserved as that initial draft. The separately named `preflight.py` is the planned authoritative driver. These additions are source preparation only; no new executable or filter workload has run.

The driver requires a full reviewed source commit containing every local preflight input, checks each corresponding Git blob and worktree hash, and verifies the exact initial proposal. It reads the parent214-source/27-binary freeze from immutable commit`33ad882da3f5bff603f4b51559f3cd4833778fee`, verifies every inherited source and executable, and pins the retained75 reference executable to SHA256`b77b90d92d5334b3b690d47a2e5d8fa7fcdbd786e5861ffa0fbd3757ea7e8b02`. The candidate source still changes only an include path from the validated fixed multiplier. A wrong or abbreviated commit, local mutation, missing dependency or changed reference stops validation.

The entire operation must hold CPU3/socket1 through `flock`, matching environment and affinity. Actual inherited lock descriptors are verified; another process merely holding the named lock is insufficient. The offline corruption tests exercise wrong source blobs, wrong environment/affinity, a real owned descriptor, a separate descriptor rejected by an existing lock, missing dependency pins, and early `-O` rejection.

Native, AVX2-only and native ASan/UBSan build the four CMake targets in fresh isolated target directories. Every compiler-generated dependency file is inspected: all repository headers must have been pinned before compilation, while consumed system headers are recorded separately and rechecked at the end. All76 geometry/output checks and the complete CLI/late-fault suite run in each mode. Full geometry digests must match across backends. The compiled measurement translation unit is unchanged from the75 parent.

Allocation-only planning must yield1016 geometries, with exactly70 selected configurations in13 cases and all62 retained geometries unchanged. Six tiny reference/current workloads compare all75 retained API rows, totaling450 semantic comparisons, including memory/probe policy, checksum, calibration, input mode and scratch accounting. Tiny timings are unclaimed. Full source/dependency and old/new binary hashes are checked again after validation. Failed attempts are retained; no attempt is overwritten.

After success and review, `freeze_preflight.py` writes a new `FREEZE.json` and local manifest without altering initial proposal bytes. It includes the entire validation evidence and all old/new binaries. The separate timing runner still requires a reviewed commit containing that final freeze and an explicit performance lease; preflight does not launch the70-row matrix.
