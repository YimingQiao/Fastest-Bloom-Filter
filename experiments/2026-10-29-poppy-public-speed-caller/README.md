# Poppy public comparison caller

This appends the47 fixed Poppy public adapters to the immutable21-configuration
Rust caller at72625673. Selection and finite486-row protocol are committed in
[the plan](../2026-10-29-poppy-public-speed-plan/README.md). No performance run is
authorized by this source stage. The original K12 body remains the control.

`derive.py` binds every parent source file and the committed selection, then
checks byte identity of every original adapter and the entire timed helper
body. Only Poppy registration/geometry, a strict final `original|reverse` flag
and an exclusion of the new fixed-n types from an old generic geometry test are
added. Reversal happens after the original shuffle and consumes no RNG.
Public constructor checks reject wrong real n or budget before workload setup.
No requested capacity, FPP, probe count or bucket count is optimized here.

The Poppy adapter supplies eight little-endian bytes to `insert_bytes` and
`contains_bytes`. Every mandatory preparation, cache test, secondary hash and
insertion Result check is charged. The singleton wrapper has the same
`inline(always)` opportunity as other adapters. A public-loop bulk adapter
reflects the available upstream API. The public size includes buckets and
cache; CSV logical bytes name buckets only and are never the memory-cap field.

The combined dependency lock is resolved offline from the prior lock input,
then captured with Cargo metadata before compilation. The dependency resolver
can introduce/update shared transitive versions; the resolution difference is
reported. All new comparison controls share the same actual dependency graph.
Neither old latencies nor identical compiler output are assumed to carry over.

Focused validation will run normal and ASan versions of four tests: the two new
Poppy tests, the existing four-phase schedule guard and the actual timed-tail
fault guard. Eight adapter fixtures preserve the real constructor capacities
but insert only1031 keys. They cover both sizes, ordinary/power-of-two buckets,
cached/uncached policies, duplicate history, full public serialization against
the public iterator path, dense outputs, tails and visible pure/fused calls.
All47 literal geometry records are checked without allocating47 full filters.
The already passed86-constructor public algorithm proof is reused.

Bounded actual executable checks will use n65536,q4096,seed42,hit50,repeats4,
calibration0,whole-input insertion, batches1/31 and original/reverse order, with
one representative Poppy plus original K12 and Range under24-bit ceilings.
Strict invalid order, wrong Poppy real n/budget, unknown/duplicate filters and
extra arguments must reject before output. Two bounded invocations of the immutable original caller establish reference
mixed-query counts/checksums for the unchanged controls, and opposite orders
must retain complete row metadata and query answers. Actual normal executable
assembly must show mandatory public Poppy work inside query/build clocks.
Failed commands remain recorded; no retries or performance promotion follow
from a compile-only or empty-disassembly success.

Offline dependency resolution completed without compiling:76 packages,61 new
transitive/library records plus the renamed caller; no common package record or
version changed. The original caller package record was replaced. Exact metadata,
command, stderr and lock difference remain in `resolution-v1/`.
