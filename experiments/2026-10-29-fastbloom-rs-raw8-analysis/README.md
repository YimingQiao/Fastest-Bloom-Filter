A later additive loader must bind this exact committed source, the committed formal producer and **complete separately committed raw archive** before invoking `analyze`; it must first replay the producer's exact commands, metadata, all raw CSVs, every trial vector, aggregate bytes and quality-reuse identities. It must reject partial data, movable Git refs, incomplete ledger and unresolved source drift. No ranking may be generated from an unsealed or partial screen.
