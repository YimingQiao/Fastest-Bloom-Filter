This comparison includes the real public raw API cost. The direct adapter passes each original key as eight little-endian bytes to public membership methods. It uses no common prehash and no artificial identity-copy phase. The other APIs pay their required common hash within the corresponding raw operation. Direct queries use zero hash scratch; common-hash queries use only the selected batch's scratch. Complete construction includes required scratch allocation and initialization, filter allocation and raw insertion. The independently fixed insertion chunk of 4096 bounds common-hash build scratch at 32 KiB. That is an explicit workspace choice, not a search for the best insertion batch.
