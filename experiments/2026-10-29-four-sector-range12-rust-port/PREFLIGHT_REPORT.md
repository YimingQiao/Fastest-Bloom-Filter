# Rust K12 port correctness evidence

The isolated native Rust K12 implementation passed its bounded correctness preflight. It is not promoted and has no Rust performance or new false-positive-rate measurements. The C++ fresh-seed strict24 bulk evidence motivated the port; matching bitmap semantics alone does not transfer its measured speed to Rust.

All five meaningful unit tests pass in each of the three Rust modes (15 executions). The ownership tests prove floor(line*T/L) and ceil partition boundaries, including nonpower2 line counts and T3/T7; real builds compare full bitmap bytes against serial insertion and verify both old and new inserted keys.

Every test/fixture child records the actual inherited allowed mask3,5,7,9,11,13,15, which the wrapper verifies are seven distinct physical socket1 cores. Scoped workers inherit that mask. This is real multi-core correctness exposure, not a throughput/scaling measurement or a per-worker fixed-core assignment. No explicit NUMA memory-binding claim is made.
