## Exact packaging

`derive.py` reads only immutable Git blobs. `proposed/rust/src/four_sector_range12.rs` changes only the helper import alias and test filename. Scalar/SIMD bodies, masks, original ordinary inline hints, allocation and dispatch are exact. The public API retains `new`, `with_byte_budget`, `size_in_bytes`, `backend`, scalar and bulk insertion/query, worker/scratch reporting, exclusive parallel insertion, immutable parallel lookup, and read-only bitmap/line inspection. Constructors floor to complete64-byte lines within128B..256MiB, retain real n and charge actual vector capacity. Input is a uniformly distributed prehashed u64; this type does not silently select a raw-key hasher.

`k12_parallel.rs` retains the proved generic physical-line insertion and owner bodies. Its backend, worker, scratch and immutable-query utilities are re-exported from existing `layout_parallel`; derivation verifies those utility bodies and `parallel::workers` are byte-identical to the tested isolated copies. Existing power-of-two and high32 range schedulers are not modified. The K12 module imports the new helper under its old local name so all kernel call sites remain exact.

For global physical line i, T workers and L lines, owner is floor(i*T/L), with slice p covering `[ceil(p*L/T), ceil((p+1)*L/T))`. The supplied index is the actual top24 address mapping. There is no high32 owner shortcut or power-of-two assumption. Complete mutable line slices preserve exclusive ownership; scalar/SIMD insertion rebases by `begin*16`. Existing worker thresholds, request0 behavior and checked scratch arithmetic remain identical.

The production delta is three additive source files plus the small `lib.patch` export. Root package/license/version/features and current defaults remain unchanged. New benchmark registration can follow as an explicit optional family; it must retain current default family selection and reject malformed selections before jobs, consistent with existing harnesses. This proposal does not include a new atomic type or modify overlapping-write semantics.
