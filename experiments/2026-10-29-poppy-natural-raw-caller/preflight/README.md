# Bounded natural-Poppy public caller proof

This additive source plan uses the reviewed caller at `d3da7464052c4f3a5c298703654e2921b37b319a` and resolved graph at `d441b2a9ce08fb3b8e5d64fda0b9808924edebe8`. It does not change the Rust sources, the 14 selected constructors, either natural input form, or any clock/workload helper. No compilation, filter execution, new calibration or formal performance screen has run at this source gate.

The fixed scope is normal plus ASan, four executables, eight focused test invocations, 146 tiny caller rows, 90 parent control reproductions, and 12 expected CLI rejections. Each profile runs the two new Poppy tests and the two existing allocation/lifetime and timed-output-fault tests. There is no broad rerun of the old library suite.

Each new semantic test constructs all 28 byte8/typed forms with their exact real `n`, FPP bits, cache policy and actual backing size. It inserts only 1,031 fixture keys per form and checks guarded public output, complete serialized bytes against a public iterator reference, allocation/drop accounting, duplicates, input immutability and length errors. Large constructors are therefore tested at a small load; this is not a 32-million-key population or FPR result. Only the seven small constructors are filled to their actual 65,536-key load in the tiny CLI checks, at query batches 1 and 31, with query power 12, seed 42, four repetitions, insert batch 4096 and calibration zero. They produce 28 rows per profile. One old default-45 case per profile reproduces the frozen raw8 case0 geometry, probe, raw-input, output and calibration fields; old latency fields are never compared. Default selection remains the old 45 APIs.

`contract.py` derives five commands per profile in registry order and validates exact RNG-derived row order, all four metric vectors and summaries, full-build versus insertion containment, zero hash scratch for both natural APIs, cache-inclusive bytes, constructor metadata and distinct byte8/typed hash-contract labels. Six bad CLIs per profile cover unknown/duplicate selection, wrong real n, wrong declared budget, negative integers and overflow. Rejections require the exact expected exit code (2 or 101), a stable source diagnostic and empty stdout. Sanitizer/runtime diagnostics in either stream fail every command, including nominally expected failures. The existing timed skip-last-write and wrong-value tests remain phase-aware and poison all implementations outside the clocks.

`bindings.py` pins the initial 38 source artifacts plus manifest, the 16 resolution artifacts plus manifest, all 87 parent anchors, the 32 original Poppy Git files, the 87-package/4,483-file prepared inventory, the two parent semantic references and the exact helper sources. Cargo metadata must reproduce the locked package/feature graph. The copied dependency collector is the already-validated workspace-aware version from `4a31f937`; relative dep-info resolves only through an exact structured target source under its manifest root or, for an actual workspace member, its metadata workspace root. Ambiguity fails. Generated inputs require a unique structured build-script package/out-dir owner. All `.d` rules and structured package/target executable identities are recorded, including nightly actual/final executable aliases. The required current adapter/test, native and upstream public modules must actually be consumed.

For each profile the driver builds tests with `--no-run` and builds the standalone caller, then closes the actual dependency graph **before** executing either binary. The parent process and all children retain the actual exclusive socket1 flock descriptor, CPU3 affinity and `BF_SOCKET_LEASE=socket1-cpu3`. Cargo/runtime override variables and unpinned Cargo configuration are rejected. Fresh `/tmp/fastest-bf-poppy-natural-raw-v1-cpu3` and `validation-v1` paths are mandatory; failures and partial artifacts are never deleted or reused silently.

After functional success, normal ELF capture records address+size identities, all folded aliases, full disassembly and relocations. It extracts every surviving raw-visible, raw-batched, raw-insert and construction/report specialization plus surviving public Poppy/WyHash callees. A symbol per constructor or per natural form is not assumed. Manual review must identify the actual byte8 and typed calls/hash work, cache/first-bit/secondary-hash behavior, dense stores, public Result handling, constructor and query clock boundaries, and absence of artificial common-hash scratch/copies. Any outlined helper or compiler-selected sharing remains an observed cost; this proof makes no speed claim.

The final driver rechecks source, package membership, actual compiler inputs, executables, tool bytes and inherited lease. Formal raw8 results and future bridge quality/latency selection are outside this bounded operation. The existing raw8 786-row run is not read by this source package.
