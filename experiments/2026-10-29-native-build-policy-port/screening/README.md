normal/ASan actual-native proof. It performs no compilation. The old public
native implementation and the policy port coexist in one executable per
language, with their original public insertion requests supplied inside the
clock. The native implementation selects the effective worker count.

requested4/8, C++/Rust, and seeds74381/164321. These seeds have already been
observed in the wrapper experiment; this native comparison is not fresh

The four-trial schedule is unchanged. Control/candidate order is ABBA with
identical absolute-position counts; the serial reference occupies only the
first/last position. Each timed arm has a fresh bitmap, identical streamed
history, full old/new presence checks and complete guarded mixed outputs.

Populated cases expose incremental insertion only. Empty cases also expose
allocation+insertion. Setup cost is recorded separately. No timed query,
FPR, external-baseline, cross-language or pooled-scenario claim is made.

allowed physical-core mask contains requestedT cores. Individual workers are
not pinned. C++ and Rust retain their different worker/coordinator contracts.

are checked against the exact fixed policy and actual native implementation.

