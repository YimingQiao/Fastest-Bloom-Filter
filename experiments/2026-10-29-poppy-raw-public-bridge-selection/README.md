It has no compiler or filter invocation. The source inventory must be committed before actual selection.

The selector retains every tied within-Poppy minimum across all 864 separate views and every one of the 20,304 size-matched alternatives, including over-budget and failed-quality points. All 47 formal cal26 records remain unpooled. The selected constructor union is not known until execution. ```sh


No old latency or calibration count becomes a new qualification. The old whole-input scratch/build-clock and later build-validation limitations stay explicit in the report.

This is a shortlist within Poppy even when it loses to other libraries. A null historical view adds no substitute. It is not a new baseline benchmark, a raw8 ranking, or a global leadership claim.
